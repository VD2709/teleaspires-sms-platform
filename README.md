A modern, high-performance web platform built for **TeleAspiresPvtLTD** — an enterprise-grade A2P (Application-to-Person) SMS, WhatsApp Business, and telecommunication services provider.

---

## ✨ Key Features

- **📱 Interactive Live SMS Composer & Simulator:** Real-time phone simulator allowing users to compose messages, select message types (OTP, Transactional, Marketing), test delivery, and view instant delivery status alerts.
- **🗺️ Global Carrier Backbone Network:** High-tech digital world map showcasing Tier-1 telecommunication routes and direct carrier hubs across 200+ countries with live telemetry indicators (`< 1.2s avg latency`).
- **🔄 Infinite Full-Width Marquee Tickers:** Seamless, continuous sliding conveyors for customer testimonials and telecom partner logos (Airtel, T-Mobile, Tata Communications, Tanla, ENTEL, etc.) with zero blank gaps across all screen sizes.
- **💬 Lead Capture & WhatsApp Integration:** Direct "Request a Quote" AJAX modal delivering inquiries straight to `info@teleaspires.com`, alongside a floating quick-connect WhatsApp chat widget.
- **⚡ Zero-Build Ultra-Fast Architecture:** Single-file production static bundle requiring zero Node.js/build steps. Loads instantly on any shared hosting (cPanel/HostingRaja) with pre-configured `.htaccess` for Gzip compression, browser caching, and automatic HTTPS redirection.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (ES6+)
- **Icons & Graphics:** SVG Vector Graphics, FontAwesome / Heroicons
- **Typography:** Inter & Space Grotesk (Google Fonts)
- **Server / Config:** Apache `.htaccess`, XML Sitemap, Robots.txt
- **Lead Capture:** FormSubmit AJAX API & WhatsApp API

## 🚀 Deployment Instructions

### Deploy to cPanel / HostingRaja:
1. Upload all files into the `public_html` directory.
2. Ensure `.htaccess` is present in the root directory.
3. Access your domain (e.g., `https://teleaspires.com/`) to view the live website!

### Run Locally:
Simply open `index.html` in any web browser (Google Chrome, Microsoft Edge, Safari, Firefox). No build command or local server required.
